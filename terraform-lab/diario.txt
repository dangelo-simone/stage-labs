terraform init: prepara la cartella a essere usata con terraform
terraform plan: crea un piano di esecuzione, fa la preview dei cambiamenti all'infrastruttura
terraform apply: crea un piano (come plan), chiede l'approvazione (con opzione -auto-approve fa da solo) e fa le operazioni indicate


script di startup della vm:
1. trova l'url repo dal metadata server e imposta webroot e path repo clonata
2. apt update e install nginx, ssl, git
3. clona repo
4. certificato ssl, prende l'ip pubblico dal metadata server e lo usa come identità
5. config nginx, listen su 80 e return 301, listen su 443, specifica certificato, root e index
6. restart nginx
7. cronjob pull repo ogni 5 minuti
