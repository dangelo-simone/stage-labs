script di startup della vm:

2. apt update e install nginx, ssl, git
3. clona repo
4. certificato ssl, prende l'ip pubblico dal metadata server e lo usa come identità
5. config nginx, listen su 80 e return 301, listen su 443, specifica certificato, root e index
6. restart nginx
7. cronjob pull repo ogni 5 minuti

3. nodo code: parso la response di llama e genero html
	const resp = $input.first().json;
	let text = resp.response;                 

	text = text.replace(/```json/gi,'').replace(/```/g,'').trim();
	const film = JSON.parse(text);

	const oggi = new Date().toLocaleDateString('it-IT', { timeZone: 'Europe/Rome' });
	const html = `<!DOCTYPE html>
	<html lang="it"><head><meta charset="utf-8">
	<title>Film brutto del giorno</title>
	<style>body{font-family:system-ui,sans-serif;max-width:680px;margin:3rem auto;padding:0 1rem;line-height:1.5}
	h1{margin-bottom:0}.meta{color:#666}.voto{font-size:2rem}</style></head>
	<body>
	<h1>Film brutto del giorno</h1>
	<p class="meta">${oggi}</p>
	<h2>${film.titolo} (${film.anno})</h2>
	<p><strong>Regia:</strong> ${film.regia}</p>
	<p>${film.motivo}</p>
	<p class="voto">Voto: ${film.voto}/10</p>
	</body></html>`;

	return [{ json: { html, date: new Date().toISOString().slice(0,10) } }];
